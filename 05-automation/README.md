# Автоматизация тестирования (Python + Selenium)

В данном разделе представлены примеры моих UI-автотестов, написанных на Python с использованием Selenium WebDriver и Pytest.

## Что автоматизировано:
* **Поиск по сайту (E-commerce)**
  * Позитивный тест: проверка того, что поиск находит существующий товар (ввод «бюстгальтер»).
  * Негативный тест: проверка корректного сообщения при вводе несуществующего слова («абракадаброкс»).

## Использованный стек:
* Python 3
* Selenium WebDriver (Chrome)
* Pytest (фреймворк для запуска тестов)
* Явные ожидания (Explicit Waits / WebDriverWait) для стабильности тестов.

## Как запустить тесты (для рекрутера):
1. Установить зависимости: `pip install pytest selenium`
2. Запустить тесты: `pytest test_search.py`
